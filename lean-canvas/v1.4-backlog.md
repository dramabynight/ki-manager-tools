# Lean Canvas v1.4 Backlog

Captured 2026-04-28, after KW18 cohort feedback session. Build after the cohort week; less-changes mode in effect for Wed/Thu.

## A. Import flow (the big one)

**Goal:** Participants come to Lean Canvas with prior work (pain points, persona, ideation MD). They shouldn't start from scratch — but they shouldn't get the canvas auto-filled either, or the learning collapses.

**Approach:** Three layers, all additive on top of Mode 2.

1. **Entry textarea: "Vorerkenntnisse einfügen"** — paste prior MD/text. Stored in state, prepended to `SYSTEM_PROMPT` as `Der Nutzer hat folgende Vorarbeit: …`
2. **Coach cites their material back** — instead of generic "Was sind deine Probleme?", AI says "In deinen Pain Points stand X. Welche zwei davon gehören wirklich ins Problem-Feld?"
3. **Field-level "💡 Vorschlag aus deinen Notizen"** — different prefix from the generic suggestion. Same accept/edit/reject flow as today. **Never silent-prefill.**

**Out of scope:** auto-fill all fields from a paste. That kills the pedagogy.

## B. Help text always visible (not click-to-reveal)

Today: `?` button toggles help panel. User has to click to discover it.

Options:
- Show help by default, click `?` to hide.
- Show a one-line hint (the `❓ question`) under the field label always; full explanation behind `?`.
- Inline placeholder = the leitfrage instead of "Problem beschreiben…"

Recommend option 2 (one-line always-visible question, expandable explanation). Lowest disruption.

## C. Onboarding / sequence guidance

Today: nothing tells a first-time user the canvas has an order or how to start.

Add: a small intro card at top with:
- "1. Wähle deinen Kontext. 2. Modus auswählen: Selbst oder Geführt. 3. Felder in der Reihenfolge 1–9 ausfüllen (Problem zuerst)."
- Numbered badges (1–9) on each field card matching `GUIDED_SEQUENCE`.

## D. Stronger save indicator

Today: faint `✓` at bottom-right of filled fields, `opacity: 0.45`.

Options:
- Increase opacity, show next to label in header.
- Tiny "gespeichert" toast on field blur.
- Already-saved subtitle on intro card: "✓ Eingaben werden lokal gespeichert" (already exists in header — reinforce per-field).

Recommend: per-field `✓` in the header bar (next to the `?` button), full opacity. Plus existing global indicator stays.

## E. Modernize UI (less soft)

Julia's read: current aesthetic is "warm pastel" — too soft.

Direction:
- Tighten radii: 14px → 8–10px on cards.
- Reduce/remove the heavy box-shadows (`0 2px 12px rgba(0,0,0,0.07)`); thin `1px` border instead.
- Consider deeper, more saturated header colors (current headers like `#C17B5A` are muted earth tones — try a more confident palette while keeping the warm base).
- Sharper typography contrast: increase weight differences, slightly larger field labels.
- Optional: dark navigation/header bar (`#2C2420` already exists in header text — could be expanded).

Out of scope for v1.4: full redesign. Goal is "leaner, more deliberate" not "different aesthetic."

## F. Smaller bits

- "✓ Fertig" at end of guided mode currently does nothing — should trigger something (export prompt? completion screen?).
- Mobile/tablet: 10-column grid breaks below ~900px. Add responsive fallback (stacked layout).
- Authentication: shared password gate in front of `/api/chat` for cohort use (ENV-based, not user accounts).
